# Usman Malik — Premium Portfolio

Modern responsive developer portfolio made with React, TypeScript, Vite, Framer Motion and Lucide icons.

## Run locally

1. Install Node.js 20+.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown.
5. For production, run `npm run build`; deploy the generated `dist` folder on Netlify, Vercel or another static host.

## Customize

- Main content: `src/main.tsx`
- Design: `src/style.css`
- Profile image: `public/profile.png`
- SEO metadata: `index.html`

No projects section is included, as requested.
